Política de Privacidad — Core to Cosmos

Última actualización: Octubre 2026

Esta Política de Privacidad describe cómo el juego Core to Cosmos: Stack Tower maneja la información de los usuarios.

1. Recopilación de Datos Personales

Core to Cosmos NO recopila, transmite, vende ni comparte ningún dato personal sensible ni información de identificación personal (PII). El juego no solicita correo electrónico, número de teléfono, ubicación geográfica en tiempo real ni acceso a la libreta de contactos.

2. Almacenamiento Local (Local Storage)

El juego almacena datos exclusivamente de manera local en el dispositivo del usuario mediante la API de localStorage del navegador/WebView. Estos datos incluyen:

  • Puntuaciones más altas y récords semanales.
  • Monedas acumuladas en el juego.
  • Niveles desbloqueados y estrellas obtenidas (1 a 3 estrellas).
  • Aspectos cosméticos (skins) adquiridos y equipados.
  • Preferencias de configuración (sonido, vibración háptica, música ambiental y guía de alineación).

Estos datos nunca salen del dispositivo del usuario y pueden eliminarse en cualquier momento borrando el almacenamiento local de la aplicación.

3. Permisos del Dispositivo

La aplicación utiliza únicamente APIs estándar del navegador para enriquecer la experiencia de juego:

  • Vibración Háptica (Vibration API): Para proporcionar retroalimentación táctil durante el apilamiento de bloques.
  • Audio (Web Audio API): Para sintetizar efectos de sonido y música ambiental procedural de forma 100% local.
  • Bloqueo de Suspensión (Screen Wake Lock API): Para evitar que la pantalla se apague mientras una partida está en curso.

4. Menores de Edad

Core to Cosmos es apto para todas las edades (categoría PEGI 3 / Para Todo Público). No contiene contenido inapropiado ni recopila información de menores.

5. Contacto

Si tiene alguna pregunta sobre esta Política de Privacidad, puede contactar al equipo de desarrollo a través del repositorio oficial del proyecto.
